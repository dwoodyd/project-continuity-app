# Immersive Wren Reference Audit

## Marketing reference: continuary.app

The marketing hero treats Wren as the scene rather than as a component. The character occupies the right half of the warm navy field, extends beyond the visible frame, and carries the luminous focal weight of the page. Copy occupies a protected left column with no enclosing card around Wren. The effect comes from a single shared background, a large character scale, and restrained text layering.

## In-app introduction reference: app.continuary.app/intro

The external browser preview rendered blank during this audit, so it cannot be relied upon as the visual baseline. The current onboarding implementation will be inspected in source and locally validated before changing it. The desired direction remains clear from the user’s feedback and the marketing reference: Wren should inhabit a full-bleed scene with copy layered in a readable zone, not be framed as video content inside a box.

## Design implications

Selected in-app Wren moments should use a shared dark field, full-area media with `object-cover`, and a protected copy gradient or panel. Informational cards such as Emotional Cycle remain contained when their small Wren asset is supporting status copy rather than forming the scene itself.
