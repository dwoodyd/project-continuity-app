# Continuary Studio Wall Requirements

Source: user-provided `pasted_content.txt`, August 16, 2026.

Continuary must give a cold book reader with a book code a no-account path into one exercise, preserving the result locally until an account is worth creating. Export must remain free at every tier and be stated as a pricing feature. All changed surfaces must preserve a 12px minimum text size, 4.5:1 body-text contrast, and 44×44px tappable targets.

The default return experience must be a Return Brief rather than a blank Today view. It should show today’s date, the last line written, the thread still open, and one Continue action. Every new writing entry must start with a date stamp and starter prompt.

The Studio Wall system is light by default: paper `#F4F5F2`, pinned-card `#E6E8E3`, graphite `#2A2D28`, pencil `#6B6F68`, and red pen `#C8452B`. Red is the sole accent and is reserved for the next action. Interface type is Archivo; user-authored writing uses iA Writer Quattro or Courier Prime. Motion is mechanical and short (120–160ms), with no theatrical fades or ambient motion. Legacy navy, amber, full-screen wordmark splash, and serif display treatments must be removed from Continuary.
